# План реорганизации и редизайна экрана настроек (SettingsActivity)

## 1. Цели и задачи

1. **Исправление неработающего функционала:**
   - Сделать так, чтобы все настройки реально влияли на поведение приложения (качество по умолчанию, папка сохранения, автоперевод, голос, аудиорежим, ограничение Wi-Fi).
2. **Удаление лишнего функционала:**
   - Полностью убрать настройку «Тема» (приложение строго тёмное, код переключения темы не используется).
3. **Информативность (под каждым пунктом текущее значение):**
   - Обеспечить динамические и понятные подзаголовки (Summary) для каждого пункта настроек с отображением его текущего статуса.
4. **Редизайн и исправление кривой вёрстки:**
   - Добавить верхнюю панель (`MaterialToolbar`) со стрелкой «Назад» и заголовком «Настройки».
   - Устранить наползание элементов на строку состояния (status bar) за счёт правильной обработки системных отступов (`fitsSystemWindows` / WindowInsets).
   - Стилизовать категории и пункты под единый стиль Material 3 (аккуратная типографика, иконки, цвета `@color/text_primary` и `@color/text_secondary` вместо ядовито-красных системных заголовков).

## 2. Анализ причин неработоспособности настроек

| Пункт настроек | Текущее состояние в коде | Причина неработоспособности | Решение |
|---|---|---|---|
| **Качество по умолчанию** (`default_quality`) | Сохраняется в Preference. Summary отсутствует. | В `ParamsFragment` список форматов содержит строки вида `1080p`, а в настройках — число `1080` или `auto`. Сопоставление часто срывается. | Унифицировать сопоставление (по числу высоты кадра или префиксу), включить `useSimpleSummaryProvider="true"`. |
| **Папка для сохранения** (`last_download_folder`) | Хранится в `SettingsRepository`, но **отсутствует на экране настроек**. | Пользователь не может посмотреть или сменить папку глобально. | Добавить пункт «Папка загрузок» в категорию «Загрузки» с показом текущего пути и вызовом системного диалога выбора папки (SAF). |
| **Только Wi-Fi** (`wifi_only`) | Сохраняется в Preference, проверяется в тестах. | `DownloadCoordinator` и `DownloadService` не вызывают `NetworkPolicy.canExecute()`, загрузка идёт независимо от сети. | Внедрить проверку `NetworkPolicy` перед запуском задачи и при смене активной сети; выводить понятный статус при паузе из-за мобильной сети. |
| **Включать перевод по умолчанию** (`translate_default`) | Читается в `ParamsFragment.onViewCreated()`. | В методе `onSuccess` анализа ссылки стоит жёсткий сброс: `switchTranslate.setChecked(false);`, игнорирующий настройку. | Использовать значение `settings.isTranslateDefault()` при успешном разборе иностранного видео. |
| **Голос по умолчанию** (`voice_default`) | Инициализируется только до ввода ссылки. | При сбросе перевода выбор не обновляется, summary отсутствует. | Применять значение из настроек при разборе ссылки, включить `useSimpleSummaryProvider="true"`. |
| **Режим звука по умолчанию** (`audio_mode_default`) | Инициализируется только до ввода ссылки. | Аналогично голосу, summary отсутствует. | Применять значение из настроек при разборе ссылки, включить `useSimpleSummaryProvider="true"`. |
| **Тема** (`theme`) | Ничего не делает, выбор не влияет на UI. | В приложении зафиксирована тема `Theme.Material3.Dark.NoActionBar`. | Удалить пункт «Тема» и категорию «Оформление» из разметки, репозитория и строковых ресурсов. |
| **Очистить кэш** (`clear_cache`) | Удаляет файлы, но не показывает размер до нажатия. | Нет предварительного подсчёта размера директории `cacheDir`. | Динамически вычислять размер кэша и показывать в summary (например, «Занято: 12.4 МБ · Нажмите для очистки»). |

## 4. Этапы реализации

### Этап 1. Исправление верстки и редизайн экрана (`activity_settings.xml` и темы)
1. **Добавление Toolbar и безопасных отступов:**
   - Переверстать `activity_settings.xml`: использовать `LinearLayout` с `android:fitsSystemWindows="true"` и `MaterialToolbar`.
   - Настроить кнопку «Назад» (`setNavigationOnClickListener(v -> finish())`), системный цвет статусбара.
2. **Стилизация PreferenceCategory и Preference:**
   - Создать единый стиль для заголовков категорий: цвет `@color/accent` сделать приглушённым или использовать аккуратный вторичный цвет `@color/text_secondary` с верхним регистром и отступами, убрав грубый дефолтный системный вид.
   - Задать `preferenceTheme` в стилях приложения, чтобы все диалоги выбора (ListPreference) и свитчи были выдержаны в Material 3 Dark.
3. **Иконки элементов:**
   - Добавить векторные иконки Material Icons: качество видео, Wi-Fi, папка, перевод, микрофон, звук, cookies, обновление, очистка корзины, информация.

### Этап 2. Удаление пункта «Тема»
1. Удалить `theme` из `preferences.xml`.
2. Удалить категорию `pref_cat_appearance` и связанные строки/массивы из `strings.xml` и `arrays.xml`.
3. Удалить `KEY_THEME` и метод `getTheme()` из `SettingsRepository.java`.
4. Обновить `SettingsRepositoryTest.java`.

### Этап 3. Реализация динамических описаний (Summary) под каждым пунктом
1. **ListPreference** (`default_quality`, `voice_default`, `audio_mode_default`):
   - Установить `app:useSimpleSummaryProvider="true"` (автоматическое отображение текущего лейбла).
2. **SwitchPreference** (`wifi_only`, `translate_default`):
   - Добавить `summaryOn` и `summaryOff` (либо кастомный listener с обновлением описания текущего статуса).
3. **Папка загрузок** (`last_download_folder`):
   - Добавить `Preference` с ключом `default_download_folder`.
   - В summary выводить текущий путь из `SettingsRepository.getDownloadFolder()`.
   - По клику открывать `OpenDocumentTree` (SAF) для выбора директории и сохранять через `SettingsRepository.setDownloadFolder()`.
4. **Размер кэша** (`clear_cache`):
   - При открытии экрана и после очистки рекурсивно считать размер файлов в `getCacheDir()` и форматировать (например, `Formatter.formatFileSize(context, size)`).
5. **Файл cookies**:
   - Добавить кнопку/действие «Удалить cookies», если файл существует, либо контекстное меню/диалог подтверждения.

### Этап 4. Исправление логики работы настроек в пайплайне
1. **Автоперевод (`translate_default`) в `ParamsFragment`:**
   - Исправить сброс в `ParamsFragment.java`: при анализе нерусскоязычного видео выставлять:
     `switchTranslate.setChecked(app.container().settings.isTranslateDefault());`
   - Применять настройки голоса и аудиорежима к видимым контролам.
2. **Качество по умолчанию (`default_quality`) в `ParamsFragment`:**
   - Сделать надёжный выбор: если в настройках стоит `1080`, искать ближайшее доступное качество `1080` (или `auto` / наивысшее, если точного совпадения нет).
3. **Ограничение Wi-Fi (`wifi_only`) в координаторе загрузок:**
   - В `DownloadCoordinator` / `DownloadWorker` перед стартом скачивания проверять:
     `if (!networkPolicy.canExecute(settings.isWifiOnly())) { ... }`
   - Переводить задачу в состояние ожидания сети (`WAITING_NETWORK`) либо показывать информативное уведомление.

### Этап 5. Тестирование и валидация
1. Запуск unit-тестов:
   `JAVA_HOME=/usr/lib/jvm/java-17-openjdk ./gradlew testDebugUnitTest`
2. Проверка линтера:
   `python3 tools/check_lint.py`
3. Сборка debug APK:
   `JAVA_HOME=/usr/lib/jvm/java-17-openjdk ./gradlew assembleDebug`
4. Установка на подключенный по Wi-Fi телефон через ADB и контрольный скриншот для подтверждения исправленной верстки.
