# yTRD Android 0.2.18-alpha

Первый тестовый выпуск самостоятельного Android-приложения. Не является стабильным релизом.

## APK для ARM

- `ytrd-android-v0.2.18-alpha-arm64-v8a.apk` — ARM64.
- `ytrd-android-v0.2.18-alpha-armeabi-v7a.apk` — 32-битный ARM.
- `ytrd-android-v0.2.18-alpha-universal-arm.apk` — оба ARM ABI.
- `SHA256SUMS` — контрольные суммы всех трёх APK.

Требуется Android 8.0 или новее. Все варианты имеют идентификатор `com.idex.ytrd`, `versionCode=15` и подписаны одним релизным сертификатом. При переходе с ранее распространявшегося **debug APK** потребуется удалить установленную debug-версию: подпись релиза отличается. Перед удалением сохраните нужные данные и скачанные файлы.

## Возможности

Загрузка YouTube-видео или аудио, настройки качества, очередь с паузой и отменой, выбор папки, субтитры и русская закадровая озвучка Yandex VOT. Для перевода в готовом APK дополнительных действий пользователя не требуется.

## Ограничения alpha

- Проверка на реальном телефоне проведена на ARM64; вариант `armeabi-v7a` пока не испытан на отдельном 32-битном устройстве.
- Перевод использует неофициальный интерфейс Yandex VOT и может перестать работать при изменении сервиса. Проект не связан с YouTube или Яндексом.
- Этот тестовый выпуск не распространяется через Google Play; обновления выходят в GitHub Releases.

Сообщайте о проблемах с версией Android, моделью устройства и шагами воспроизведения, **не прикладывая cookies, токены и другие секреты**.
